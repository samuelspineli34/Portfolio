Este repositório centraliza minha trajetória técnica, reunindo projetos desenvolvidos durante a graduação em Ciência da Computação na PUC Minas e soluções implementadas em ambiente corporativo. O objetivo principal é demonstrar a aplicação prática de conceitos de arquitetura de software, automação e processamento de dados.

## Estrutura do Portfólio

O portfólio foi construído como um projeto de engenharia moderno, utilizando:

*   **Runtime:** Bun para gerenciamento de pacotes e execução.
*   **Build Tool:** Vite para otimização de ativos e performance.
*   **Linguagem:** TypeScript, garantindo tipagem estática e segurança de código.
*   **Estilização:** Tailwind CSS com suporte nativo a temas (Dark/Light mode).
*   **Localização:** Sistema de internacionalização (i18n) customizado para suporte em Português e Inglês.
*   **CI/CD:** Pipeline automatizada via GitHub Actions para deploy contínuo no GitHub Pages.

## Categorias de Projetos

Os projetos aqui expostos estão divididos em três frentes principais:

1.  **Sistemas de Engenharia:** Aplicações full-stack complexas com foco em padrões de projeto como DAO, DTO e controle de acesso granular (RBAC).
2.  **Pesquisa e TCC:** Implementações voltadas para Machine Learning e Ciência de Dados, com destaque para o processamento de sinais de áudio e mel-espectrogramas.
3.  **Ferramentas e IoT:** Soluções de baixo nível, incluindo automação de extração de mídia (FFmpeg) e integração de hardware (ESP32) com interfaces mobile (Flutter).

## Como Executar este Projeto Localmente

Para rodar o ambiente de desenvolvimento, certifique-se de ter o Bun instalado em sua máquina:

1. Instalar dependências:
   ```bash
   bun install
   ```

2. Iniciar servidor local:
   ```bash
   bun dev
   ```

3. Gerar build de produção:
   ```bash
   bun run build
   ```
